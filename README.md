## 🎯 Target Focus Areas for Data Engineering
- **SQL & Relational Databases:** Window functions (`ROW_NUMBER`, `DENSE_RANK`, `LEAD/LAG`), CTEs, recursive queries, self-joins, aggregations.
- **Python Data Structures:** Hash maps (`dict`), sets, two pointers, sliding window, heaps, frequency counting.
- **Efficiency:** Optimizing algorithmic runtime and memory footprint ($O(N)$ vs $O(N^2)$).
